# Today's Class
## Practical Steps

- Create an HTML file.
- Copy the file path and paste it into the browser.
- Save the file after every update in VS Code (`Ctrl + S`).
- Refresh the browser to view the latest changes.
## Topics Covered

- Heading Tags (`<h1>` to `<h6>`)
- Paragraph Tag (`<p>`)
- Text Formatting Tags
  - Bold (`<b>`)
  - Italic (`<i>`,)
  - Underline (`<u>`)
  - Delete (`<del>`)
  - Other basic formatting tags
- List Tags
  - Ordered List (`<ol>`)
  - Unordered List (`<ul>`)
  - List Item (`<li>`)
